One line, 200 characters at most, in English: the elevator pitch a city pigeon gives investors for its startup.

> Investors, I'm a city pigeon: I run Coo-ber, rideshare for birds — no drivers, no surge pricing, fares paid in breadcrumbs. I already own the skies; I just need seed money. Literally.

`main.py` writes that line to `/output/entry.txt`, then reads it back and checks it: valid UTF-8, one line, 1–200 characters.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
